# Mock 数据说明

这里的 JSON 只服务于第一版前后端联调，全部内容均为中性占位数据，不代表真实商品、真实参数、真实用户反馈或真实外部来源。

- `videos.json`：演示视频元数据和归一化对象框。
- `products.json`：识别接口返回的候选商品。
- `category-profiles.json`：动态条件字段和验真维度配置。
- `evidence.json`：可点击查看的三类演示证据。
- `verification-results.json`：验真结果页面使用的占位结论。
- `comparison-results.json`：横评入口占位结构。

只有项目负责人/成员 A 直接维护此目录。任何字段变更先同步 `docs/04-api-contract.md`。
